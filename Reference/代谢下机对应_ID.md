# 代谢组下机数据：首先得到什么，如何获得分子式和代谢物 ID？

> **核心结论：不是先确定 HMDB ID，也不是仪器直接测出化学式。对于常见的非靶向 LC–MS／LC–MS/MS 代谢组，仪器先采集原始信号，软件处理后得到检测特征，并为其分配 Feature ID／Peak ID。分子式、候选化合物及数据库编号属于后续注释信息，没有统一、固定的获取先后顺序。** [参考 1][1] [参考 2][2]

## 一、最先得到的是什么？

仪器首先记录质荷比（m/z）、信号强度及对应的采集时间等信息。经过峰提取、保留时间校正和跨样本匹配等处理，软件形成可以用于比较各样本的特征表。[参考 1][1]

下面的数值仅作示意，不代表真实实验结果：

| Feature ID | m/z（质荷比） | RT（保留时间） | 样本 1 峰面积 | 样本 2 峰面积 |
|---|---:|---:|---:|---:|
| F001 | 181.0707 | 3.20 min | 100000 | 150000 |

**这里的 F001 只是检测特征的编号，不是某种代谢物的身份编号。** 此时可以知道这个特征在不同样本中的信号大小，但不一定知道它是什么物质。特征提取与化合物注释是不同的步骤。[参考 1][1] [参考 2][2]

还要注意：**Feature ID／Peak ID 通常由数据处理软件分配，不是仪器直接测出的化学性质。** [参考 2][2]

## 二、Feature ID、Formula、Compound ID 和 HMDB ID 有什么区别？

| 字段 | 中文含义 | 实际表示什么 | 不能仅凭它得出的结论 |
|---|---|---|---|
| **Feature ID／Peak ID** | 特征编号／峰编号 | 软件用于追踪某个检测特征或峰的内部编号 | 不能证明已经确定具体代谢物 |
| **Formula** | 分子式，属于化学式的一种 | 分子的元素组成，例如 C₆H₁₂O₆ | 不能单独确定唯一的化学结构 |
| **Compound ID** | 化合物编号 | 含义取决于软件或检测机构，可能是内部编号，也可能是数据库条目编号 | 不能只看列名就认定其来源和鉴定可信度 |
| **HMDB ID** | HMDB 数据库条目编号 | 注释结果所关联的 HMDB 条目 | 不能证明仪器已经直接、唯一地鉴定出该物质 |

**检测特征、分子式、具体化学结构和数据库条目是不同层面的信息，不能混为一谈。** 不同软件中的字段名称与注释方式也可能不同。[参考 2][2] [参考 3][3] [参考 4][4]

### 特别注意 Compound ID

`Compound ID` 不是一个在所有代谢组报告中都有相同定义的字段。因此，不能笼统地说“先确定 Compound ID，再确定 HMDB ID”。要结合报告的字段说明、编号实例和所使用的数据库，判断它究竟是内部记录编号，还是数据库中的化合物编号。[参考 3][3]

## 三、分子式和代谢物身份是怎样得到的？

可以用下面的逻辑理解，但它不是所有软件都严格执行的唯一流程：[参考 3][3] [参考 4][4]

```text
仪器采集原始信号
    ↓
软件提取、整理检测特征
    ↓
得到 m/z、RT、峰面积等信息
并分配 Feature ID／Peak ID
    ↓
开展代谢物注释
结合准确质量、同位素分布、离子形式、MS/MS 等证据
    ↓
推断候选分子式／匹配候选化合物
    ↓
获得或关联名称、分子式、HMDB ID 等信息
```

**仅有准确质量，不一定能唯一确定分子式；即使分子式确定，也不等于具体化合物已经确定。** 因为同一分子式可能对应不同结构，结构层面的注释还需要更多证据。[参考 4][4]

## 四、是否一定先确定分子式，再得到 HMDB ID？

**不一定。** 常见情况可以分为两种：[参考 3][3] [参考 4][4]

| 注释方式 | 可以怎样理解 |
|---|---|
| **先推断分子式，再搜索候选结构** | 根据质谱证据筛选分子式，再结合碎片等信息寻找候选化合物，随后关联数据库编号 |
| **先匹配谱库或数据库候选条目** | 匹配结果可以同时返回候选名称、分子式、结构信息以及已有数据库编号 |

因此，结果表里出现 `Formula`，**不一定表示这个分子式已经被独立推算并验证**；出现 `HMDB ID`，**也不等于这个代谢物已经被确证**。它们可能都是同一次候选注释所附带的信息，仍需结合匹配证据和注释可信度判断。[参考 3][3] [参考 4][4]

## 五、怎样理解检测公司最终交付的结果表？

检测公司交付的“代谢物结果表”，可能已经完成了从原始数据处理到数据库注释的多个步骤。因此，你看到第一列是 `Compound ID` 或 `HMDB ID`，**并不代表分析过程中首先确定的是这一项；表格列顺序不等于分析步骤顺序。** [参考 1][1] [参考 3][3]

阅读自己的报告时，最关键的是确认：`Compound ID` 的具体定义，以及该条代谢物注释依据的是准确质量、MS/MS 谱库匹配，还是还有其他支持证据。不能仅凭“有名称、有分子式、有数据库 ID”判断身份已经可靠确定。[参考 3][3] [参考 4][4]

---

## 一句话总结

> **先检测到“这个信号／特征”，再判断“它可能是什么物质”；分子式描述元素组成，HMDB ID 标记数据库条目，而 Compound ID 必须看具体报告如何定义。**
