# ChIP-Seq

**ChiP（Chromatin Immunoprecipitation，染色质免疫共沉淀）**：ChIP-Seq 用于确定蛋白质和 DNA 的互作情况；包括 **TF ChIP** 和 **Histone ChIP**。TF（Transcription Factor） 作为能结合基因 5` 端上游特异序列的蛋白质的反式作用因子，能特异性结合真核基因的顺式作用元件如：启动子、增强子等，以激活或抑制基因的转录，现多用于确定靶向蛋白也就是 TF 是否结合靶向基因的特定区域



### Basic



**染色质**：真核生物在间期细胞核内由 DNA、组蛋白、非组蛋白和少量 RNA 组成的核酸蛋白复合体
