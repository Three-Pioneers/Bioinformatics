# Metabonomics

## 代谢组学概述

**代谢组学**是对生物体内代谢产物的组成及其变化进行系统性研究的学科，主要研究**分子量小于 1000 **的内源性小分子[^1]，包括糖类、脂质、芳香烃、氨基酸等。动物约有 2500 种，微生物约有 1500 种，植物约有 20 万种

生物机体中的生理活动由基因、蛋白质以及代谢物共同调节，而上游大分子如糖类、蛋白质的变化大多最终会体现在代谢物层面，但代谢物也能通过与上游基因、蛋白质相互作用参与众多生理过程的调控

代谢组学数据库：/Data_all/Databases/hmdb_metabolites

### 代谢组学发展历程

早期人们使用的核磁共振技术（NMR，Nuclear Magnetic Resonance）存在样本需求量大，灵敏度低等问题，随着质谱（MS，Mass Spectrum）与液相（LC，Liquid Chromatography）、气相（GC，Gas Chromatography）色谱的联合使用获得代谢数据，通过质荷比、相对丰度等信息反映代谢物的结构和丰度

到 21 世纪，三位荧光液相色谱、同位素示踪等方法获得了广泛应用，随着单细胞的发展现在能检测单个细胞中的代谢物含量及其变化

### 代谢组学的样本制备

由于代谢物能随着体液被排出机体，所以尿液、血液、动物粪便提取物、植物组织提取物等是代谢组学研究中的常用样本，此外，临床上或动植物实验取得的实体组织样本等复杂的生物样本也可以是代谢组学的研究对象

代谢组学样本在收集时需要进行严格的把控，收集样本时应该根据实验设计综合考虑采样时间、样本保存条件以及保存时间等实验因素的一致性；收集临床生物样本时，要尽量保证实验组与对照组之间年龄、性别、膳食、生活作息、病史、用药状况等多方面因素的一致性

代谢物容易受到环境中众多因素的影响，如样本中残存酶降解原有代谢物产生新代谢物，因此需要尽快对样本进行淬灭，并且进行合适的提取

代谢物处于生命活动的下游，动态波动性大，为增加实验数据的可靠性和说服力，需要增加生物学重复次数，如下：

1. 植物样本：至少 6 次生物学重复，建议 8 次以上
2. 模式动物及微生物样本：至少 8 次生物学重复，建议 10 次以上
3. 临床样本：至少 30 次生物学重复，建议 50 次以上

## Question

1. 代谢组学如何确定通过色谱分离出来的就是单个化合物，而且如何确定相同分子质量的不同化合物或者相同分子式的同分异构体在质谱打断时不会受影响

首先色谱是根据代谢物在固定相（化合柱）被溶解到流动相（气相或者液相）中的能力不同从而导致的流动时间差异来区分化合物，主要是根据化合物的性质，包括极性、疏水性、官能团等。随后跟着流动相流入质谱后进行电离，加正离子成阳性化合物或者抛弃质子形成阴性化合物，先进行一级质谱检测整个离子质荷比，再进入碰撞池进行二级质谱，检测出打断碎片的质荷比。色谱中对于保留时间过于接近的是有可能在存在多个化合物的，所以可能出现多个化合物分离到一起的情况（共洗脱）；其次相同分子质量的不同化合物在打断时由于化学键的能量不一样，所以打断后会出现不同的离子片段。对于同分异构体，除非是位置异构体（基团都相同，只有基团位置不一样）和立体异构体不能区分化合物，其他都能分辨

2. 代谢组学如何进行定量，比较的是什么

代谢物含量和进入质谱离子数量与信号强度和峰面积是正相关，所以可根据峰面积（信号强度：intensity）推断代谢物含量，且只能比较不同样本同一代谢物的相对含量，由于 m/z、RT、离子转化率不同，所以不同代谢物之间不能通过直接比较峰面积判断绝对含量高低，当做标准曲线后就可通过靶向代谢比较绝对定量

3. 代谢组学化合物定性时，Mass 和 m/z 为何相差很大也能定性为同一类物质

m/z 是 MS1 测定的离子质荷比，是通过色谱的化合物进入质谱后，电离带上质子、钠离子或失去质子形成正电荷或负电荷，因此相差是这些离子的分子质量可初步判断，需要根据离子片段打断后的 MS/MS、RT 综合判断是否属于同一物质；同时由于电离时或许会带有不同的正电离子也可能带有负电荷，所以一个化合物或许会被检测到多次，同一极性需要通过加减 MS1 和离子池中正负电离子分子质量的差值以及 MS/MS 判断是否为同一化合物，不同极性之间也以此判断

4. 信号强度（intensit）除多次检测、高分辨率鉴定后确认为零，绝大多数为 NULL

不轻易写 0 是因为如果有峰但检测不到，贸然认定为零在差异比较相对浓度时，会出现 500 / 0.01 = 50000 和 500 / 0 = 正无穷，这两种相差极大的结论，会错误得出代谢物及其显著增大的结论。因此有四种情况：1.质谱仪只能检测到 0.1，而峰为 0.01，此时不代表没有只能说检测不出来，注释为 NOT_DETECTED；2.质谱仪检测出来了 0.5，但是可信阈值设定为 1，认为此峰值不可信，也设定为 NULL，注释为 BELOW_LOQ；3.峰为空值但软件不支持空值，因此设定为一个随意值如最低检测值的一半，注释为 IMPUTED；4.经过多次检测、高分辨率检测、标准品验证后确定不含有这个化合物，才可设定为 0

5. 代谢物鉴定的原理

根据 MS1 也就是一级质谱的范围检测到的带加和离子的化合物的分子质量初步计算推断可能的化合物的分子式，但是一级质谱是检测峰附近的分子质量再根据二级质谱 MS/MS 缩小区间内的峰检测出来的分子质量
