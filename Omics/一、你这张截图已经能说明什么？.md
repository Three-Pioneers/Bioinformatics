### 2. 设置样本类型和分组

文件导入后，按下面填写：

| 文件              | Type／样本类型 | Class ID／分组 |
| ----------------- | -------------- | -------------- |
| `QC-1_POS`        | **QC**         | `QC`           |
| `Control-022_POS` | **Sample**     | `Control`      |
| `PRPP-002_POS`    | **Sample**     | `PRPP`         |

这里要区分：

**Control 是你的生物学对照组，Type 仍然是 `Sample`；`Blank` 指空白进样。**

其余信息这样处理：

- **Acquisition type / MS method：**按照采集方法填写；从截图判断，优先核对是否为 **DDA**。
- **Batch：**确实属于同一采集批次时，均填 `1`。
- **Analytical order：**填真实进样顺序，不能直接拿样本编号当进样顺序。
- **Dilution factor：**没有额外稀释差异时，可保留 `1`。

MS-DIAL 5 可以在文件列表中分别指定采集类型、样本类型和分组。[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/Explanation on each parameter of MS-Dial 5.html?utm_source=chatgpt.com)

### `Centroid` 和 `Profile` 怎么选？

**不要因为文件是 Thermo `.raw`，就直接认定 MS1 必须选 `Profile`。**

按输入路线判断：

| 你实际导入的数据                             | 设置方法                                                     |
| -------------------------------------------- | ------------------------------------------------------------ |
| 官方 MS-DIAL 5 直接读取 Thermo `.raw`        | 官方说明后端通常读取为质心数据，因此通常 MS1、MS/MS 均选 **Centroid** |
| 转换时已经对 MS1、MS2 都做了质心化的 `.mzML` | 两项均选 **Centroid**                                        |
| 保留了轮廓数据的 `.mzML` / `.abf`            | 按文件实际情况选 **Profile**；MS1 与 MS2 可能不同            |

官方 MS-DIAL 5 教程专门说明了厂商原始文件的这一读取行为。[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/?utm_source=chatgpt.com)

如果不清楚转换过程，可以用软件附带的 **RawDataViewer** 分别查看一个 MS1 和一个 MS2 扫描，放大某个质谱峰：质心数据表现为离散峰，轮廓数据保留峰两侧的连续采样点。**看的是质谱峰，不是随时间变化的色谱峰。**[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/Determining MS data types.html?utm_source=chatgpt.com)

## 五、后面的数值参数，第一轮怎么设置？

由于截图没有仪器型号，**下面的数值用于初次试跑，正式参数需要结合 QC 的峰形、噪声和质量误差调整。**

### 1. `Data collection`：数据范围与质量容差

| 参数                     | 第一轮设置                                                   |
| ------------------------ | ------------------------------------------------------------ |
| **Retention time range** | 覆盖完整采集时间，单位是 **min**；例如实际采集 20 分钟，就覆盖 `0–20` |
| **MS1 mass range**       | 如果整批方法与截图一致，可设为 `70–1050`                     |
| **MS/MS mass range**     | 先保留能覆盖全部碎片的默认范围，不能直接照搬 MS1 的下限      |
| **MS1 tolerance**        | 高分辨数据试跑可先保留软件默认；官方教程列出的值是 `0.01 Da` |
| **MS/MS tolerance**      | 高分辨数据试跑可先保留软件默认；官方教程列出的值是 `0.025 Da` |

这里的 **Da 与 ppm 不是同一个单位**。如果 MS2 是低分辨离子阱数据，上述 MS/MS 容差就不能直接照用。[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/Explanation on each parameter of MS-Dial 5.html?utm_source=chatgpt.com)

### 2. `Peak detection`：找色谱峰

第一轮可以先保留平滑和峰宽的默认设置，重点关注：

- **Minimum peak height：最低峰高。**应根据 QC 的信号与噪声决定。阈值低会保留更多弱信号，也会带入更多噪声；阈值高会漏掉部分弱峰。可以用 RawDataViewer 的峰高分布辅助判断。[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/Determine the optimal minimum peak height.html?utm_source=chatgpt.com)
- **Mass slice width：质量切片宽度。**官方教程给出的经验起点是 Orbitrap 约 `0.05 Da`、Q-TOF 约 `0.1 Da`，需要先确认仪器类型。它与谱库匹配容差是不同参数。[mtbinfo.github.io - Hiroshi Tsugawa](https://systemsomicslab.github.io/mtbinfo.github.io/MS-DIAL/tutorial.html?utm_source=chatgpt.com)

**目前不要只凭截图里的 `Base Peak Intensity`，就把最低峰高定成一个固定值。**

### 3. `Spectrum deconvolution / MS2Dec`

如果确认是 DDA，第一轮先保留默认设置即可。这一页的解卷积参数对 DIA 数据尤其重要。[mtbinfo.github.io](https://systemsomicslab.github.io/mtbinfo.github.io/MS-DIAL/tutorial.html?utm_source=chatgpt.com)

## 六、谱库和加合离子怎么设置？

### 1. `Identification`：加载参考谱库

你做一般代谢组，可以先使用现成的 **LC-MS/MS 参考 MSP 谱库**。

官方入口：

[MS-DIAL 软件与谱库下载页面](https://systemsomicslab.github.io/compms/msdial/main.html?utm_source=chatgpt.com)

在页面中找到 **MS-DIAL metabolomics MSP spectral kit**，对应选择：

| 项目 | 对应谱库                                  |
| ---- | ----------------------------------------- |
| POS  | **ESI(+)-MS/MS from authentic standards** |
| NEG  | **ESI(-)-MS/MS from authentic standards** |

这些是官方提供的标准品 MS/MS 谱库入口。[MS-DIAL](https://systemsomicslab.github.io/compms/msdial/main.html?utm_source=chatgpt.com)

下载并解压后，在 `Identification / Database setting` 中选择对应 `.msp` 文件。

**如果公共谱库中的 RT 不是用与你相同的色谱方法得到的，先关闭：**

- `Use retention time for scoring`
- `Use retention time for filtering`

这里关闭的是**谱库鉴定中的 RT 条件**；后面样本之间的峰对齐仍然需要使用 RT。[mtbinfo.github.io](https://systemsomicslab.github.io/mtbinfo.github.io/MS-DIAL/tutorial.html?utm_source=chatgpt.com)

### 2. `Adduct ion`：加合离子

我建议第一轮先从常见类型开始：

| 模式 | 起步选择            |
| ---- | ------------------- |
| POS  | `[M+H]+`、`[M+Na]+` |
| NEG  | `[M-H]-`            |

之后根据流动相添加剂和实际谱图，增加铵加合、甲酸加合、乙酸加合等类型。软件允许勾选或自定义需要考虑的加合离子。[mtbinfo.github.io](https://systemsomicslab.github.io/mtbinfo.github.io/MS-DIAL/tutorial.html?utm_source=chatgpt.com)

## 七、对齐、运行和检查结果

在 **`Alignment`** 页面：

- **Reference file：**选择一个峰形正常、信号覆盖充分的 QC。三个文件试跑时，可以先用所选的 `QC-1_POS`。
- **RT tolerance / MS1 tolerance：**第一轮保留默认，运行后检查同一特征在不同样本中的峰是否正确对应。
- **Blank filtering：**没有导入真正的空白样本，就不要启用按空白过滤。
- **Isotope tracking：**普通非标记代谢组不勾选同位素示踪。

设置完点击 **`Run`**，完成后保存项目。官方教程支持以 QC 为对齐参考，并在处理后导出峰表及谱图。[MS-DIAL 5 tutorial](https://systemsomicslab.github.io/msdial5tutorial/Explanation on each parameter of MS-Dial 5.html?utm_source=chatgpt.com)

第一次跑完，我建议先检查三个方面：

1. **是否检测到了正常色谱峰**：挑几个强、中、弱信号，看峰的左右边界是否合理。
2. **是否有特征关联到 MS/MS**：你原始文件有 MS2，因此应检查是否正确关联到了部分特征。
3. **三个样本的同一特征是否对齐正确**：不能仅看最终表里出现了多少行。

确认后，用同样的设置建立完整 POS 项目；再建立 NEG 项目，把离子模式、谱库和加合离子改成负离子对应设置。
